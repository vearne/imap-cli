# imap-cli Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `imap-cli`, a Go CLI over `emersion/go-imap/v2` that lets an LLM list, search, read, flag, move and batch-delete IMAP mail, with credentials read from environment variables.

**Architecture:** Stateless single binary: each invocation dials → logs in → runs one command → logs out. Cobra subcommands delegate to a thin `internal/client` wrapper; `internal/output` renders human text or `--json`; `internal/testenv` spins up the library's own in-memory IMAP server for integration tests.

**Tech Stack:** Go ≥ 1.25, `github.com/emersion/go-imap/v2` v2.0.0-beta.8, `github.com/emersion/go-message` v0.18.2, `github.com/spf13/cobra` (latest v1).

**Spec:** `docs/superpowers/specs/2026-09-30-imap-cli-design.md` (approved 2026-09-30)

## Global Constraints

- Module path: `github.com/vearne/imap-cli`; binary name `imap-cli`.
- Credentials ONLY from env vars: `IMAP_HOST`, `IMAP_PORT` (default `993`), `IMAP_USERNAME`, `IMAP_PASSWORD`, `IMAP_TLS` (`tls`|`starttls`|`none`, default `tls`).
- Every message-referencing command uses **UIDs** (pass `imap.UIDSet` to Fetch/Store/Move/Copy — the library auto-issues UID variants; verified at `imapclient/fetch.go:176`, `imapclient/move.go:31` of go-imap v2.0.0-beta.8).
- `--json` on every output command; default output is human-aligned text. Errors → stderr, exit code 1 (`cobra RunE` returning error).
- Date flags parse `2006-01-02` and map to `SearchCriteria.SentBefore` / `SentSince` (envelope Date header).
- go-message automatically decodes transfer encoding + charset (incl. GBK) to UTF-8 — do NOT import `golang.org/x/text` directly (spec's charset concern is covered by the library; verified `go-message/entity.go:24`).
- Tests use the stdlib `testing` package only (no testify) and `imapserver/imapmemserver` as the real IMAP server.
- Every changed Go file must pass `gofmt -l` (empty output) and `go vet ./...` before commit.
- Commits: one per task, conventional style (`feat:`, `test:`, `docs:`).

```go
// internal/config/config.go
package config

import (
	"fmt"
	"os"
	"strconv"
)

const (
	TLSTLS      = "tls"
	TLSStartTLS = "starttls"
	TLSNone     = "none"
)

type Config struct {
	Host     string
	Port     int
	Username string
	Password string
	TLSMode  string
}

func (c Config) Addr() string { return fmt.Sprintf("%s:%d", c.Host, c.Port) }

func Load() (Config, error) {
	cfg := Config{Port: 993, TLSMode: TLSTLS}
	var err error
	if cfg.Host, err = required("IMAP_HOST"); err != nil {
		return cfg, err
	}
	if cfg.Username, err = required("IMAP_USERNAME"); err != nil {
		return cfg, err
	}
	if cfg.Password, err = required("IMAP_PASSWORD"); err != nil {
		return cfg, err
	}
	if v := os.Getenv("IMAP_PORT"); v != "" {
		p, err := strconv.Atoi(v)
		if err != nil || p < 1 || p > 65535 {
			return cfg, fmt.Errorf("IMAP_PORT %q is not a valid port number", v)
		}
		cfg.Port = p
	}
	if v := os.Getenv("IMAP_TLS"); v != "" {
		switch v {
		case TLSTLS, TLSStartTLS, TLSNone:
			cfg.TLSMode = v
		default:
			return cfg, fmt.Errorf("IMAP_TLS must be one of tls, starttls, none; got %q", v)
		}
	}
	return cfg, nil
}

func required(name string) (string, error) {
	v := os.Getenv(name)
	if v == "" {
		return "", fmt.Errorf("required environment variable %s is not set", name)
	}
	return v, nil
}
```

```go
// internal/testenv/testenv.go
package testenv

import (
	"net"
	"testing"
	"time"

	"github.com/emersion/go-imap/v2"
	"github.com/emersion/go-imap/v2/imapclient"
	"github.com/emersion/go-imap/v2/imapserver"
	"github.com/emersion/go-imap/v2/imapserver/imapmemserver"
)

// Server is an in-memory IMAP server for integration tests.
type Server struct {
	Addr string
	User *imapmemserver.User
	srv  *imapserver.Server
	ln   net.Listener
}

func Start(t *testing.T, caps ...imap.Cap) *Server {
	t.Helper()
	if len(caps) == 0 {
		caps = []imap.Cap{imap.CapIMAP4rev1, imap.CapIMAP4rev2, imap.CapUIDPlus, imap.CapMove}
	}
	capSet := imap.CapSet{}
	for _, c := range caps {
		capSet[c] = struct{}{}
	}
	memSrv := imapmemserver.New()
	user := imapmemserver.NewUser("testuser", "testpass")
	if err := user.Create("INBOX", nil); err != nil {
		t.Fatalf("create INBOX: %v", err)
	}
	memSrv.AddUser(user)

	ln, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		t.Fatalf("listen: %v", err)
	}
	srv := imapserver.New(&imapserver.Options{
		NewSession: func(conn *imapserver.Conn) (imapserver.Session, *imapserver.GreetingData, error) {
			return memSrv.NewSession(), nil, nil
		},
		Caps:         capSet,
		InsecureAuth: true,
	})
	go srv.Serve(ln) //nolint:errcheck — test server
	t.Cleanup(func() { ln.Close() }) //nolint:errcheck
	return &Server{Addr: ln.Addr().String(), User: user, srv: srv, ln: ln}
}

func (s *Server) Client(t *testing.T) *imapclient.Client {
	t.Helper()
	c, err := imapclient.DialInsecure(s.Addr, nil)
	if err != nil {
		t.Fatalf("dial: %v", err)
	}
	t.Cleanup(func() { c.Logout().Wait() }) //nolint:errcheck
	return c
}

// Append seeds one message and returns its UID.
func (s *Server) Append(t *testing.T, mbox string, raw string, flags []imap.Flag, when time.Time) imap.UID {
	t.Helper()
	c := s.Client(t)
	cmd := c.Append(mbox, int64(len(raw)), &imap.AppendOptions{Flags: flags, Time: when})
	if _, err := cmd.Write([]byte(raw)); err != nil {
		t.Fatalf("append write: %v", err)
	}
	if err := cmd.Close(); err != nil {
		t.Fatalf("append close: %v", err)
	}
	data, err := cmd.Wait()
	if err != nil {
		t.Fatalf("append wait: %v", err)
	}
	if data == nil || data.UID == 0 {
		t.Fatal("append returned no UID (server must advertise UIDPLUS)")
	}
	return data.UID
}
```

```go
// internal/client/client.go
package client

import (
	"crypto/tls"
	"fmt"

	"github.com/emersion/go-imap/v2/imapclient"
	"github.com/vearne/imap-cli/internal/config"
)

func Dial(cfg *config.Config) (*imapclient.Client, error) {
	var c *imapclient.Client
	var err error
	switch cfg.TLSMode {
	case config.TLSTLS:
		c, err = imapclient.DialTLS(cfg.Addr(), nil)
	case config.TLSStartTLS:
		c, err = imapclient.DialStartTLS(cfg.Addr(), nil)
	case config.TLSNone:
		c, err = imapclient.DialInsecure(cfg.Addr(), nil)
	default:
		return nil, fmt.Errorf("unknown TLS mode %q", cfg.TLSMode)
	}
	if err != nil {
		return nil, fmt.Errorf("connect %s: %w", cfg.Addr(), err)
	}
	if err := c.Login(cfg.Username, cfg.Password).Wait(); err != nil {
		c.Logout().Wait() //nolint:errcheck
		return nil, fmt.Errorf("login as %q failed: %w\nHints: QQ/163 mailboxes need an authorization code (授权码), not the web login password; Gmail needs an app password with IMAP enabled in settings", cfg.Username, err)
	}
	return c, nil
}

// Run dials, logs in, executes fn with the logged-in client, then logs out.
func Run(cfg *config.Config, fn func(c *imapclient.Client) error) error {
	c, err := Dial(cfg)
	if err != nil {
		return err
	}
	fnErr := fn(c)
	if err := c.Logout().Wait(); err != nil && fnErr == nil {
		return fmt.Errorf("logout: %w", err)
	}
	return fnErr
}
```

```go
// internal/uidset/uidset.go
package uidset

import (
	"fmt"
	"strconv"
	"strings"

	"github.com/emersion/go-imap/v2"
)

// Parse parses a user-supplied UID set like "1:500,800,1000:1200".
func Parse(s string) (imap.UIDSet, error) {
	var set imap.UIDSet
	for _, part := range strings.Split(s, ",") {
		if part == "" {
			return nil, fmt.Errorf("invalid UID set %q: empty element", s)
		}
		lo, hi, ok := strings.Cut(part, ":")
		start, err := parseUID(lo)
		if err != nil {
			return nil, fmt.Errorf("invalid UID set %q: %w", s, err)
		}
		if !ok {
			set.AddNum(start)
			continue
		}
		stop, err := parseUID(hi)
		if err != nil {
			return nil, fmt.Errorf("invalid UID set %q: %w", s, err)
		}
		if stop < start {
			return nil, fmt.Errorf("invalid UID set %q: range %d:%d is reversed", s, start, stop)
		}
		set.AddRange(start, stop)
	}
	return set, nil
}

func parseUID(s string) (imap.UID, error) {
	n, err := strconv.ParseUint(s, 10, 32)
	if err != nil || n == 0 {
		return 0, fmt.Errorf("%q is not a positive UID", s)
	}
	return imap.UID(n), nil
}
```

```go
package cmd

import (
```

```go
	listFrom    string
	listSubject string
	listSince   string
	listBefore  string
	listUnread  bool
	listLimit   int
)

var listCmd = &cobra.Command{
	Use:   "list",
	Short: "Search and list messages (envelope summary)",
	RunE: func(cmd *cobra.Command, args []string) error {
		crit := &imap.SearchCriteria{}
		if listFrom != "" {
			crit.Header = append(crit.Header, imap.SearchCriteriaHeaderField{Key: "From", Value: listFrom})
		}
		if listSubject != "" {
			crit.Header = append(crit.Header, imap.SearchCriteriaHeaderField{Key: "Subject", Value: listSubject})
		}
		if listSince != "" {
			tm, err := parseDate(listSince)
			if err != nil {
				return err
			}
			crit.SentSince = tm
		}
		if listBefore != "" {
			tm, err := parseDate(listBefore)
			if err != nil {
				return err
			}
			crit.SentBefore = tm
		}
		if listUnread {
			crit.NotFlag = append(crit.NotFlag, imap.FlagSeen)
		}

		return runWithFolder(func(c *imapclient.Client, folder string) error {
			// SEARCH runs against the selected mailbox — SELECT must come first.
			if _, err := c.Select(folder, nil).Wait(); err != nil {
				return fmt.Errorf("select %s: %w", folder, err)
			}
			uids, err := searchUIDs(c, crit)
			if err != nil {
				return err
			}
			msgs, err := fetchSummaries(c, uids)
			if err != nil {
				return err
			}
			sort.Slice(msgs, func(i, j int) bool { return msgs[i].Date.After(msgs[j].Date) })
			if listLimit > 0 && len(msgs) > listLimit {
				msgs = msgs[:listLimit]
			}
			out := cmd.OutOrStdout()
			if jsonOut {
				return output.WriteJSON(out, msgs)
			}
			return output.PrintMessages(out, msgs)
		})
	},
}

func parseDate(s string) (time.Time, error) {
	tm, err := time.Parse("2006-01-02", s)
	if err != nil {
		return time.Time{}, fmt.Errorf("invalid date %q: use YYYY-MM-DD", s)
	}
	return tm, nil
}

func searchUIDs(c *imapclient.Client, crit *imap.SearchCriteria) ([]imap.UID, error) {
	data, err := c.UIDSearch(crit, nil).Wait()
	if err != nil {
		return nil, fmt.Errorf("search: %w", err)
	}
	return data.AllUIDs(), nil
}

// fetchSummaries fetches envelopes for uids; the mailbox is already selected.
func fetchSummaries(c *imapclient.Client, uids []imap.UID) ([]output.Message, error) {
	if len(uids) == 0 {
		return nil, nil
	}
	set := &imap.UIDSet{}
	for _, uid := range uids {
		set.AddNum(uid)
	}
	bufs, err := c.Fetch(set, &imap.FetchOptions{
		UID: true, Envelope: true, Flags: true, InternalDate: true, RFC822Size: true,
	}).Collect()
	if err != nil {
		return nil, fmt.Errorf("fetch: %w", err)
	}
	msgs := make([]output.Message, 0, len(bufs))
	for _, b := range bufs {
		m := output.Message{UID: uint32(b.UID), Size: b.RFC822Size}
		if b.Envelope != nil {
			m.Subject = b.Envelope.Subject
			m.Date = b.Envelope.Date
			if len(b.Envelope.From) > 0 {
				m.From = b.Envelope.From[0].Addr()
			}
		}
		if m.Date.IsZero() {
			m.Date = b.InternalDate
		}
		for _, fl := range b.Flags {
			switch fl {
			case imap.FlagSeen:
				m.Seen = true
			case imap.FlagFlagged:
				m.Flagged = true
			}
		}
		msgs = append(msgs, m)
	}
	return msgs, nil
}
```

```go
			if b.Envelope != nil {
				res.Subject = b.Envelope.Subject
				if len(b.Envelope.From) > 0 {
					res.From = b.Envelope.From[0].Addr()
				}
				if !b.Envelope.Date.IsZero() {
					res.Date = b.Envelope.Date.Format(time.RFC1123Z)
				}
				res.To = joinAddrs(b.Envelope.To)
				res.Cc = joinAddrs(b.Envelope.Cc)

			if err := walkBody(raw, &res); err != nil {
				return err

func joinAddrs(addrs []imap.Address) string {
	parts := make([]string, 0, len(addrs))
	for _, a := range addrs {
		parts = append(parts, a.Addr())
	}
	return strings.Join(parts, ", ")
}

func walkBody(raw []byte, res *ReadResult) error {
	mr, err := mail.CreateReader(bytes.NewReader(raw))
	if err != nil {
		return fmt.Errorf("parse message: %w", err)
	}
	for {
		part, err := mr.NextPart()
		if err == io.EOF {
			break
		}
		if err != nil {
			return fmt.Errorf("walk mime: %w", err)
		}
		switch h := part.Header.(type) {
		case mail.AttachmentHeader:
			name, _ := h.Filename()
			size := 0
			if n, err := io.Copy(io.Discard, part.Body); err == nil {
				size = int(n)
			}
			res.Attachments = append(res.Attachments, attachment{Filename: name, Size: size})
		case mail.InlineHeader:
			mediaType, _, err := h.ContentType()
			if err != nil {
				mediaType = "text/plain"
			}
			body, readErr := io.ReadAll(part.Body)
			if readErr != nil {
				return fmt.Errorf("read part: %w", readErr)
			}
			switch mediaType {
			case "text/plain":
				if res.TextBody == "" {
					res.TextBody = string(body)
				}
			case "text/html":
				if res.HTMLBody == "" {
					res.HTMLBody = string(body)
				}
			}
		}
	}
	if res.TextBody != "" {
		res.HTMLBody = "" // html is only a fallback when no text/plain part exists
	}
	return nil
}

func printReadText(w io.Writer, res ReadResult) error {
	fmt.Fprintf(w, "From:    %s\n", res.From)
	fmt.Fprintf(w, "To:      %s\n", res.To)
	if res.Cc != "" {
		fmt.Fprintf(w, "Cc:      %s\n", res.Cc)
	}
	fmt.Fprintf(w, "Subject: %s\n", res.Subject)
	fmt.Fprintf(w, "Date:    %s\n", res.Date)
	fmt.Fprintf(w, "\n%s\n", res.TextBody)
	if res.TextBody == "" && res.HTMLBody != "" {
		fmt.Fprintf(w, "[html]\n%s\n", res.HTMLBody)
	}
	if len(res.Attachments) > 0 {
		fmt.Fprintln(w, "\nAttachments:")
		for _, a := range res.Attachments {
			fmt.Fprintf(w, "  %s (%d bytes)\n", a.Filename, a.Size)
		}
	}
	return nil
}
```

```go
	Use:   "move <uid-set> <dest-folder>",
	Short: "Move messages to another mailbox",
	Args:  cobra.ExactArgs(2),
	RunE: func(cmd *cobra.Command, args []string) error {
		set, err := uidset.Parse(args[0])
		if err != nil {
			return err
		}
		return runWithFolder(func(c *imapclient.Client, folder string) error {
			if _, err := c.Select(folder, nil).Wait(); err != nil {

func moveUIDs(c *imapclient.Client, folder, dest string, set imap.UIDSet) error {
	if len(set) == 0 {
		return fmt.Errorf("empty UID set")
	}
	if c.Caps().Has(imap.CapMove) {
		if _, err := c.Move(set, dest).Wait(); err != nil {
			return fmt.Errorf("move to %s: %w", dest, err)
		}
		return nil
	}
	// Fallback: COPY + \Deleted + EXPUNGE. Note: EXPUNGE removes ALL \Deleted
	// messages in the folder, which is safe in this stateless CLI (single command
	// owns the whole session) but worth knowing.
	if _, err := c.Copy(set, dest).Wait(); err != nil {
		return fmt.Errorf("copy to %s: %w", dest, err)
	}
	del := &imap.StoreFlags{Op: imap.StoreFlagsAdd, Flags: []imap.Flag{imap.FlagDeleted}, Silent: true}
	if err := c.Store(set, del, nil).Close(); err != nil {
		return fmt.Errorf("mark deleted: %w", err)
	}
	if _, err := c.Expunge().Collect(); err != nil {
		return fmt.Errorf("expunge: %w", err)
	}
	return nil
}
```

```markdown
# imap-cli

一个面向"人 + 大模型"的 IMAP 命令行工具，基于 [emersion/go-imap v2](https://github.com/emersion/go-imap)。
典型用法：让 LLM 通过 `list` 找出目标邮件（拿 UID），确认后用 `delete` 批量删除旧邮件。

## 安装

    go install github.com/vearne/imap-cli@latest

## 配置（环境变量）

| 变量 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `IMAP_HOST` | 是 | — | 如 `imap.gmail.com` |
| `IMAP_PORT` | 否 | `993` | |
| `IMAP_USERNAME` | 是 | — | |
| `IMAP_PASSWORD` | 是 | — | Gmail 用应用专用密码；QQ/163 用授权码（不是网页登录密码） |
| `IMAP_TLS` | 否 | `tls` | `tls` / `starttls` / `none` |

使用前需在邮箱设置中开启 IMAP 服务。

## 命令

    imap-cli folders [--counts]                     # 列出文件夹
    imap-cli list [--from S] [--subject S] [--since DATE] [--before DATE]
                   [--unread] [--limit N] [--folder F] [--json]
                                                    # 搜索并列出邮件（新→旧）
    imap-cli read <uid> [--raw] [--folder F] [--json]
                                                    # 读单封邮件
    imap-cli mark <uid-set> read|unread|flagged|unflagged
    imap-cli move <uid-set> <dest-folder>
    imap-cli delete <uid-set> [--dry-run]

`<uid-set>` 语法：`5`、`1:500`、`1:500,800,1000:1200`。

## 典型工作流（批量删除旧邮件）

    # 1. 找出 2024 年之前的订阅邮件
    imap-cli list --before 2024-01-01 --from newsletter@example.com --json
    # 2. 核对将删除的范围
    imap-cli delete 1:500 --dry-run
    # 3. 执行删除（不可恢复！）
    imap-cli delete 1:500

## ⚠️ 注意

- **delete 是真删除**（IMAP `\Deleted` + `EXPUNGE`），不可恢复。先 `--dry-run`。
- **Gmail**：直接 delete 会从所有视图消失；想走回收站请 `move` 到 `[Gmail]/Trash`。
- UID 跨会话稳定，但邮箱被重建（UIDVALIDITY 变化）后需重新 `list`。
```
